<objective>
Remove the `study:` namespace prefix from study jar dependency entry IDs. Study jars should use their plain name as the dependency entry ID. Add collision prevention: error on add_study_jar if name matches a real dependency ID, and auto-unload study jars when a dependency with the same name appears after refresh_dependencies or load_project.

Purpose: Simplify the ID scheme -- study jars are already distinguishable by `category: 'study'` and `group: 'study'`. The `study:` prefix was redundant namespace pollution that made jar glob patterns awkward (users had to know about `study:*` vs plain names).

Output: Updated study jar domain logic, workspace sync, refresh/load tools, and all related tests.
</objective>
