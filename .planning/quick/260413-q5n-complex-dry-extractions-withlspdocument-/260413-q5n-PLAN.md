Add two new exported functions to tool-helpers.ts:

**1. withLspDocument wrapper:**

```ts
import type { LspClient } from 'ts-lsp-client';

export async function withLspDocument<T>(
	lspClient: LspClient,
	fileUri: string,
	sourceText: string,
	fn: () => Promise<T>,
): Promise<T> {
	await lspClient.didOpen({
		textDocument: { uri: fileUri, languageId: 'java', version: 1, text: sourceText },
	});
	try {
		return await fn();
	} finally {
		try { await lspClient.didClose({ textDocument: { uri: fileUri } }); } catch {}
	}
}
```

This replaces the 6 duplicated didOpen/try/didClose patterns in find-definition, find-references, find-implementations, get-symbol-info, list-members, and type-hierarchy.

**2. resolveClassSource helper:**

```ts
export async function resolveClassSource(
	loadedProject: LoadedProject,
	className: string,
	jar?: string,
): Promise<
	| { success: true; sourceJarId: string; sourceText: string; entryPath: string }
	| { success: false; kind: 'jar-not-found'; jar: string }
	| { success: false; kind: 'jar-not-available'; jar: string }
	| { success: false; kind: 'class-not-found'; entryPath: string; jar?: string }
>
```

Implementation:
- Use `classNameToEntryPath(className)` to get the entry path
- If `jar` is specified: look up dep in `loadedProject.dependencyJars`, check exists + available, then read via `createSourceAdapter(jarReader, dep, loadedProject.rootPath).readEntry(entryPath)` and return `{ success: true, sourceJarId: jar, sourceText: buffer.toString('utf-8'), entryPath }`
- If no jar: call `getFilteredDependencies(loadedProject.dependencyJars, loadedProject.filterConfig)`, run `sortByPriority(Array.from(filtered.entries()))`, iterate sorted deps skipping unavailable, try reading entryPath from each, return first success
- On failure: return appropriate `{ success: false, kind: ... }` result

Import `getFilteredDependencies` from `'../project/jar-registry.js'`, `jarReader` from `'./shared-jar-reader.js'`, `createSourceAdapter` from `'../browsing/source-adapter.js'`, `LspClient` type from `'ts-lsp-client'`.
