<objective>
Fix Minecraft source jar detection so projects using Loom's per-project cache (MC 1.19+ with newer Loom such as 1.16-SNAPSHOT) actually load. Currently the resolvers only construct the global-cache path (`~/.gradle/caches/fabric-loom/minecraftMaven/...`), so any project that writes its merged sources jar to `<projectRoot>/.gradle/loom-cache/minecraftMaven/...` (with a hash-suffixed `minecraft-merged-<hash>/` artifact dir) fails with SOURCES_JAR_NOT_FOUND even though the jar exists.

Purpose: Restore project loading for the broken case (e.g. ~/Documents/Projects/Fabric/Pockets) while keeping every existing global-cache project working. The hash in `minecraft-merged-<hash>` is unpredictable from gradle.properties, so the resolver must glob the project-local artifact dir rather than construct the path verbatim.

Output:
- `resolveSourcesJarPath` and `resolveCompiledJarPath` become async, accept the project root path, probe the project-local cache first (globbing `minecraft-merged-*` for the hash-suffixed artifact id), and fall back to the global cache.
- Loader call sites in `loadFabricMod` and `reloadFabricModConfig` are awaited and pass the project root.
- Tests cover both locations and the miss case.
- CLAUDE.md updated to reflect the dual-location reality.
</objective>

    3. Helper to probe the project-local cache by listing the `net/minecraft/` dir and finding the artifact dir whose name is exactly `<artifactPrefix>` OR matches `<artifactPrefix>-<10 hex chars>`:
       ```typescript
       async function probeProjectLocal(
           projectRoot: string,
           artifactPrefix: string,
           version: string,
           filenameSuffix: string,  // '-sources.jar' or '.jar'
       ): Promise<string | null> {
           const netMinecraft = join(projectRoot, '.gradle', 'loom-cache', 'minecraftMaven', 'net', 'minecraft');
           let entries: string[];
           try {
               entries = await readdir(netMinecraft);
           } catch {
               return null;  // no project-local cache
           }
           // Match exact prefix OR prefix-<hash>. The hash is typically 10 hex chars but accept any -<alnum> suffix to be safe.
           // IMPORTANT: don't match `minecraft-merged-deobf` when looking for `minecraft-merged` (deobf is its own prefix).
           const hashRegex = new RegExp(`^${artifactPrefix}(-[a-f0-9]+)?$`);
           const candidates = entries.filter(e => hashRegex.test(e) && (artifactPrefix === 'minecraft-merged-deobf' || !e.startsWith('minecraft-merged-deobf')));
           for (const dirName of candidates) {
               const versionDir = join(netMinecraft, dirName, version);
               // Filename uses the FULL dir name (with hash) as prefix.
               const filename = `${dirName}-${version}${filenameSuffix}`;
               const candidate = join(versionDir, filename);
               try {
                   await access(candidate);
                   return candidate;
               } catch {
                   continue;
               }
           }
           return null;
       }
       ```

    4. Helper to compute the legacy global-cache path (always returned even if missing — caller checks existence):
       ```typescript
       function globalCachePath(
           artifactPrefix: string,
           version: string,
           filenameSuffix: string,
       ): string {
           const base = join(homedir(), '.gradle', 'caches', 'fabric-loom', 'minecraftMaven', 'net', 'minecraft');
           // Global cache uses the bare artifact prefix (no hash suffix).
           return join(base, artifactPrefix, version, `${artifactPrefix}-${version}${filenameSuffix}`);
       }
       ```

    5. Public functions:
       ```typescript
       export async function resolveSourcesJarPath(
           config: GradleConfig,
           projectRoot: string,
       ): Promise<string> {
           const { artifactPrefix, version } = artifactInfo(config);
           const local = await probeProjectLocal(projectRoot, artifactPrefix, version, '-sources.jar');
           if (local) return local;
           return globalCachePath(artifactPrefix, version, '-sources.jar');
       }

       export async function resolveCompiledJarPath(
           config: GradleConfig,
           projectRoot: string,
       ): Promise<string> {
           const { artifactPrefix, version } = artifactInfo(config);
           const local = await probeProjectLocal(projectRoot, artifactPrefix, version, '.jar');
           if (local) return local;
           return globalCachePath(artifactPrefix, version, '.jar');
       }
       ```
