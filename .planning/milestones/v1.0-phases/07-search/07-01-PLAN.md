  <behavior>
    EntryIndex.getAllClasses():
    - Returns all top-level classes with fqn, className, packageName, isInnerClass: false
    - Returns all non-anonymous inner classes with fqn using $-separated className, isInnerClass: true
    - Excludes anonymous inner classes (e.g., MinecraftClient$1)
    - Returns empty array for empty EntryIndex
    - Inner class FQN format: "net.minecraft.client.MinecraftClient$Options" (package.outerClass$InnerName)

    searchClasses() - pattern matching:
    - Glob pattern `*Client` matches `MinecraftClient` but NOT `net.minecraft.client.MinecraftClient` (single segment)
    - Glob pattern `**.*Client` matches `net.minecraft.client.MinecraftClient`
    - Glob pattern `net.minecraft.client.*` matches classes directly in that package
    - Glob pattern `net.minecraft.**` matches classes in any sub-package
    - Glob pattern `*$Options` matches inner classes like `MinecraftClient$Options` in any package
    - Case-insensitive by default: `*client` matches `MinecraftClient`
    - Case-sensitive when caseSensitive=true: `*client` does NOT match `MinecraftClient`

    searchClasses() - kind filtering:
    - When kind is omitted, all types returned (type/access still populated from class declaration)
    - When kind=["interface"], only interfaces returned
    - When kind=["class", "enum"], classes and enums returned
    - Kind filtering happens after pattern matching (only reads source for matched classes)

    searchClasses() - deduplication:
    - Same class in multiple jars produces one result with multiple jar entries
    - Jar entries include id and category

    searchClasses() - sorting:
    - Primary sort by highest-priority jar category (minecraft=0, mod-source=1, fabric-api=2, library=3)
    - Secondary sort alphabetical by FQN

    searchClasses() - pagination:
    - Default offset=0, limit=250
    - Response includes offset, limit, total (total BEFORE pagination)
    - Offset past end returns empty results with correct total
    - Total reflects count after kind filtering, not before

    searchClasses() - jar scoping:
    - jars parameter filters which jars to search (picomatch on jar IDs)
    - When omitted, searches all jars
  </behavior>

    **Step 2: Create `src/browsing/search.ts`:**

    Export types:
    ```typescript
    export interface SearchClassResult {
    	fqn: string;
    	type: string;      // "class" | "interface" | "enum" | "record" | "@interface"
    	access: string;    // "public" | "protected" | "private" | "package-private"
    	jars: Array<{ id: string; category: JarCategory }>;
    }

    export interface SearchResponse {
    	results: SearchClassResult[];
    	offset: number;
    	limit: number;
    	total: number;
    }

    export interface SearchOptions {
    	pattern: string;
    	caseSensitive?: boolean;
    	kind?: string[];
    	jars?: string[];
    	offset?: number;
    	limit?: number;
    }
    ```

    Export function:
    ```typescript
    export async function searchClasses(
    	options: SearchOptions,
    	dependencies: Map<string, DependencyEntry>,
    	filterConfig: FilterConfig,
    	rootPath: string,
    	jarReaderInstance: JarReader,
    ): Promise<SearchResponse>
    ```

    Implementation pipeline:
    1. Apply `getFilteredDependencies(dependencies, filterConfig)` to get base jar set
    2. If `options.jars` provided, further filter with `picomatch(options.jars)` on jar IDs
    3. Sort jars by priority using `CATEGORY_PRIORITY` (import pattern from read-source.ts or define locally: `{ minecraft: 0, 'mod-source': 1, 'fabric-api': 2, library: 3 }`)
    4. Create FQN matcher: `const matchPattern = options.pattern.replaceAll('.', '/'); const isMatch = picomatch(matchPattern, { nocase: !(options.caseSensitive ?? false) });`
    5. For each jar: create SourceAdapter, call `adapter.listJavaEntries()`, build EntryIndex (using module-level cache `Map<string, EntryIndex>` with `getOrBuildIndex` pattern), call `index.getAllClasses()`
    6. For each class from getAllClasses: convert FQN dots to slashes `fqn.replaceAll('.', '/')`, test against `isMatch`. If match, add to `resultMap: Map<string, { fqn, type: null, access: null, jars: [{ id, category }] }>`. If FQN already in map, push new jar entry.
    7. Kind filtering: always read class declarations for all matched classes to populate type/access. For each entry in resultMap, try reading from first available jar (construct entry path from FQN: `fqn.lastIndexOf('.')` to split package/class, `packagePart.replaceAll('.', '/') + '/' + classPart + '.java'`). Use `parseClassDeclaration` on first 4KB. Set `result.type` and `result.access`. If kind filter is provided and type not in filter, delete from resultMap. If source unreadable, set type/access to `"unknown"`.
    8. Convert resultMap values to array, sort by: `Math.min(...jars.map(j => CATEGORY_PRIORITY[j.category] ?? 99))` ascending, then `fqn.localeCompare` ascending.
    9. Record `total = sorted.length`, slice with `offset` (default 0) and `limit` (default 250).
    10. Return `{ results: sliced, offset, limit, total }`.
