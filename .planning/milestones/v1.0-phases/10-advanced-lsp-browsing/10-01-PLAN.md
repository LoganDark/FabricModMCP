Create `src/tools/list-members.ts` implementing `registerListMembersTool(server: McpServer)`:

**Input schema:**
- `class`: z.string() -- FQN (e.g., `net.minecraft.client.MinecraftClient`)
- `jar`: z.string().optional() -- specific jar ID (default: search all jars for the class)
- `project`: z.string().optional() -- project name

**Flow:**
1. Resolve project via projectStore.resolveProject(project) with standard DomainError catch
2. Check JDT LS availability (same pattern as find_definition: check `loadedProject.jdtls?.available && loadedProject.jdtls.client`)
3. Convert FQN to entry path (same logic as find_definition: last dot splits package/class, dots to slashes, append .java)
4. Find the class source: if `jar` specified, read from that jar; otherwise search all filtered jars by priority order (same sortByPriority pattern as find_definition)
5. Build file URI via `createUriMapper(jdtls.tempDir, jdtls.jarIdToDirName).toFileUri(jarId, entryPath)`
6. didOpen with source text, languageId 'java', version 1
7. Call `lspClient.documentSymbol({ textDocument: { uri: fileUri } })` 
8. didClose (in try/finally)
9. Transform DocumentSymbol[] response into structured output:

**Transform function `transformSymbol(sym: DocumentSymbol)`:**
```typescript
{
  name: sym.name,
  kind: SYMBOL_KIND_NAME[sym.kind] ?? `unknown(${sym.kind})`,
  detail: sym.detail ?? null,
  deprecated: sym.tags?.includes(1) ?? false,  // SymbolTag.Deprecated = 1
  range: {
    start: { line: sym.range.start.line + 1, character: sym.range.start.character + 1 },
    end: { line: sym.range.end.line + 1, character: sym.range.end.character + 1 },
  },
  selectionRange: {
    start: { line: sym.selectionRange.start.line + 1, character: sym.selectionRange.start.character + 1 },
    end: { line: sym.selectionRange.end.line + 1, character: sym.selectionRange.end.character + 1 },
  },
  children: sym.children?.map(transformSymbol) ?? [],
}
```

10. Return `makeSuccess({ jar: jarId, class: className, members: transformedSymbols }, { provenance })` with text summary like "Found {N} top-level members in {className}"

**Also handle SymbolInformation[] response defensively:** If result is an array and items have `location` instead of `range`, map them to flat members (no children). This handles the case where JDT LS ignores hierarchicalDocumentSymbolSupport.
