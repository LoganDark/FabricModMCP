1. Create `src/project/dependency-discovery.ts` exporting:

```typescript
export interface DiscoveryResult {
	dependencies: Map<string, DependencyEntry>;
	summary: {
		total: number;
		withSources: number;
		withoutSources: number;
	};
}

export async function discoverDependencies(config: GradleConfig, sourcesJarPath: string, projectRootPath: string): Promise<DiscoveryResult>;
```

Implementation of `discoverDependencies`:

**Step 0 -- Seed entries:**
- Add `"minecraft"` entry: id="minecraft", group="com.mojang", artifact="minecraft", version=config.minecraftVersion, category="minecraft", sourcesJarPath=sourcesJarPath (the already-resolved MC sources jar), available=true
- Add `"src"` entry: id="src", group="", artifact="", version="", category="mod-source", sourcesJarPath=null (mod source is a directory, not a jar -- null is correct), available=true
- Skip dependencies with configuration "minecraft" or "mappings" from further processing (they are internal Loom deps)

**Step 1 -- Strategy A: Minecraft Libraries (mojang_minecraft_info.json):**
- Path: `join(homedir(), '.gradle', 'caches', 'fabric-loom', config.minecraftVersion, 'mojang_minecraft_info.json')`
- Read file, JSON.parse, extract `libraries[].name` (format: `group:artifact:version`)
- For each library: call `findSourcesJar(group, artifact, version)` to check for sources
- Create DependencyEntry with category="library", id=`${group}:${artifact}`
- If mojang_minecraft_info.json doesn't exist, log warning and skip (don't fail)

**Step 2 -- Strategy B: Fabric API Modules:**
- Only if `config.fabricApiVersion` is defined
- Try Loom cache POM first: `join(homedir(), '.gradle', 'caches', 'fabric-loom', 'fabric-api', `fabric-api-${config.fabricApiVersion}.pom`)`
- Fallback to modules-2 cache: `findPomInModules2('net.fabricmc.fabric-api', 'fabric-api', config.fabricApiVersion)`
- Parse POM with `parsePomDependencies()`, filter to compile-scope only
- Each module gets category="fabric-api", id=`${groupId}:${artifactId}`
- For each module: call `findSourcesJar()` to check for sources
- If POM not found: add a single "net.fabricmc.fabric-api:fabric-api" entry with available=false and log warning

**Step 3 -- Strategy C: Other Declared Dependencies:**
- Filter `config.dependencies` to exclude: configuration "minecraft", "mappings", artifact "fabric-api", artifact "fabric-loader" (loader rarely has useful sources)
- For each remaining dependency: call `findSourcesJar()`, create DependencyEntry with category="library"
- Follow transitive deps via POM traversal:
  - Find POM in modules-2 cache using helper `findPomInModules2(group, artifact, version)` that reads SHA1 dirs similar to `findSourcesJar` but for `.pom` files
  - Parse POM, filter to compile-scope, recurse
  - Track visited coordinates in `Set<string>` (key: `group:artifact:version`) for cycle detection
  - Depth limit: 5 levels
  - Skip dependencies without explicit version (parent-inherited)

**Helper: `findPomInModules2(group, artifact, version): Promise<string | null>`**
- Same pattern as `findSourcesJar` but looks for `${artifact}-${version}.pom`

**Summary calculation:**
- total = map.size (excluding "minecraft" and "src")
- withSources = count of entries where available=true (excluding "minecraft" and "src")
- withoutSources = total - withSources
