**2. Create `src/jdtls/uri-mapper.ts`:**

The URI mapper translates between file:// URIs pointing to extracted source files and the project's jar-based model. Extraction layout:
```
{tempDir}/
  minecraft/net/minecraft/client/MinecraftClient.java
  fabric-api__fabric-networking-api-v1/net/fabricmc/...
  src/com/example/mymod/MyMod.java
```

Directory naming rule: Replace `:` with `__` in jar IDs for filesystem safety (e.g., `fabric-api:fabric-networking-api-v1` becomes `fabric-api__fabric-networking-api-v1`).

Export these functions:

```typescript
export function jarIdToDirName(jarId: string): string
```
Replaces `:` with `__`.

```typescript
export function dirNameToJarId(dirName: string): string
```
Replaces `__` with `:`.

```typescript
export interface UriMapping {
  jar: string;        // jar ID
  entryPath: string;  // path within jar (e.g., "net/minecraft/client/MinecraftClient.java")
}

export function createUriMapper(tempDir: string, jarIdToDirNameMap: Map<string, string>)
```

Returns an object with two methods:
- `toFileUri(jarId: string, entryPath: string): string` — builds `file://{tempDir}/{dirName}/{entryPath}`
- `fromFileUri(uri: string): UriMapping | null` — parses URI back to jar ID + entry path. Returns null if the URI does not match the temp dir prefix. Strip `file://` prefix, remove tempDir prefix, split on first `/` to get dirName, rest is entryPath. Use `dirNameToJarId()` to convert dirName back to jar ID. Cross-check against the jarIdToDirNameMap to ensure the jar ID is valid; return null if not.

Also export:
- `entryPathToClassName(entryPath: string): string` — converts `net/minecraft/client/MinecraftClient.java` to `net.minecraft.client.MinecraftClient` (strip `.java`, replace `/` with `.`).

Create `src/jdtls/context-extractor.ts` with a single exported function:

```typescript
export function extractEnclosingContext(source: string, targetLine: number): ContextSnippet
```

`targetLine` is 1-based.

Algorithm:
1. Split source into lines.
2. From `targetLine`, scan backward looking for method declaration pattern:
   `^\s*((@\w+.*\n\s*)*)(public|protected|private|static|final|abstract|synchronized|native|\s)*[\w<>\[\],\s?]+\s+\w+\s*\(`
   Use a simpler multi-line approach: scan backward line-by-line looking for a line matching `METHOD_DECL_RE = /^\s*(?:@\w+|public|protected|private|static|final|abstract|synchronized|native|default)\b/` that also contains `(` (method params) or is followed by a line with `(`.
3. If found a method-like declaration within 50 lines backward:
   - If the targetLine is between the declaration and the opening `{`:
     - Return just the method signature lines (kind: 'method')
   - If the targetLine is inside the method body (after `{`):
     - Find the matching closing `}` by counting brace depth from the opening `{`
     - Return the full method from declaration through closing `}` (kind: 'method')
4. If no method found, scan backward for field pattern:
   `FIELD_RE = /^\s*(public|protected|private|static|final|volatile|transient|\s)*([\w<>\[\],\s?]+)\s+\w+\s*(=|;)/`
   If the targetLine itself matches, return that line (kind: 'field'). If multiline (ends with `,` or `+`), extend to `;`.
5. If no field found, scan backward for class/interface/enum/record declaration:
   `CLASS_RE = /^\s*(public|protected|private|static|final|abstract|sealed|non-sealed)?\s*(class|interface|enum|record)\s+/`
   If found within 10 lines backward, return the declaration line(s) up to `{` (kind: 'class').
6. Fallback: return 5 lines before and 5 lines after targetLine, clamped to file bounds (kind: 'fallback').

Return a `ContextSnippet` with `snippet` (the extracted text), `startLine`, `endLine`, and `kind`.
