## E2E User Flows (4/4)

1. **Add study jar** — add_study_jar → createStudyJar → addProjectJar → syncStudyJarToWorkspace → extract + classpath + notify + wait
2. **Browse study jar sources** — add → getDependenciesForTool → list_packages/list_classes/search_classes/read_source all see study jar
3. **Remove study jar** — remove_study_jar → unsyncStudyJarFromWorkspace → removeProjectJar → evictEntryIndex → delete from map
4. **Refresh survival** — refresh_dependencies re-registers study jars, checks staleness, preserves studyJars map
