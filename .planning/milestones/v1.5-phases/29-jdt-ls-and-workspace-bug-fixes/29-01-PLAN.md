export function classNameToEntryPath(className: string): string {
	const lastDot = className.lastIndexOf('.');
	if (lastDot === -1) return `${className}.java`;
	const packagePath = className.substring(0, lastDot).replaceAll('.', '/');
	const simpleNameWithInner = className.substring(lastDot + 1);
	return `${packagePath}/${simpleNameWithInner}.java`;
}

**FIX-04 — Type hierarchy cycle detection:**
In `src/tools/type-hierarchy.ts`, add a `Set<string>` named `seen` before the `while (true)` loop at line 119. At the start of each iteration, after getting `supers`, compute the FQN of the superclass candidate using `toClassReference(superclass).fqn`. If the FQN is already in `seen`, break. Otherwise, add it to `seen`. This prevents infinite loops on circular hierarchies while returning all supertypes collected up to the cycle point. Do NOT throw an error — just break silently.

**FIX-05 — Inner class FQN in read_source:**
In `src/tools/read-source.ts`, after the `className` parameter is received (around line 36), detect if className contains `$`. If so:
1. Extract `outerClassName` by stripping everything from the first `$` onward (same pattern as `read-member.ts` line 73)
2. Extract `innerName` as the part after the last `$`
3. Call `classNameToEntryPath(outerClassName)` instead of `classNameToEntryPath(className)`
4. After reading the source text successfully, scan the source for the inner class declaration using a regex like `/^\s*(?:public\s+|private\s+|protected\s+)?(?:static\s+)?(?:abstract\s+|final\s+)?(?:class|interface|enum|record)\s+${innerName}\b/m` — find the line number where it appears
5. If found, add `innerClass: { name: innerName, startLine: lineNumber }` to the `sources` array entries in the response data
6. If not found (anonymous class, etc.), return the full outer source without the hint

Apply this logic to BOTH code paths in read_source (specific jar and all-jars search). The `entryPath` variable is used for both paths, so setting it early from `outerClassName` handles both.

Update `classNameToEntryPath` to NOT change behavior — the fix is in read_source itself, not in the shared utility, to limit scope per CONTEXT.md decision.
