    ```typescript
    const FIELD_KINDS = new Set(["field", "constant", "enumMember"]);
    const METHOD_KINDS = new Set(["method", "constructor"]);

    export function buildMemberFqn(
    	classFqn: string,
    	memberName: string,
    	memberKind: string,
    ): string | null {
    	// Strip trailing () from name to prevent double-parens (JDT LS includes them)
    	const cleanName = memberName.replace(/\(\)$/, '');

    	if (METHOD_KINDS.has(memberKind)) {
    		return `${classFqn}#${cleanName}()`;
    	}
    	if (FIELD_KINDS.has(memberKind)) {
    		return `${classFqn}#${cleanName}:`;
    	}
    	return null; // classes, interfaces, enums, packages don't get FQN
    }
    ```

    **Create src/browsing/member-enrichment.ts:**

    ```typescript
    import type { TransformedSymbol, EnrichedSymbol, EnrichedMethodSymbol, EnrichedFieldSymbol, EnrichedClassSymbol } from './types.js';
    import type { TypeReference } from './member-types.js';
    import { parseDetail } from './detail-parser.js';
    import { extractImports, createTypeResolver } from './import-resolver.js';
    import { buildMemberFqn } from './member-fqn.js';

    const CLASS_KINDS = new Set(['class', 'interface', 'enum']);

    export async function enrichSymbols(
    	symbols: TransformedSymbol[],
    	sourceText: string,
    	classFqn: string,
    	resolvePackage: (packageName: string) => Promise<string[]>,
    ): Promise<EnrichedSymbol[]> {
    	const imports = extractImports(sourceText);
    	const resolveType = createTypeResolver(imports, resolvePackage);
    	return Promise.all(symbols.map(sym => enrichOne(sym, classFqn, resolveType)));
    }
    ```

    The `enrichOne` function:
    1. Recursively enriches children first (via Promise.all). If a child is a class/interface/enum, derive its inner class FQN as `${classFqn}$${child.name}` before recursing.
    2. Calls `parseDetail(sym.detail, sym.kind, resolveType)` to get MemberReference or null.
    3. If parsed?.kind === "method": return spread of sym + memberFqn (from buildMemberFqn) + parameters + returnType + enriched children as EnrichedMethodSymbol.
    4. If parsed?.kind === "field": return spread of sym + memberFqn + fieldType + enriched children as EnrichedFieldSymbol.
    5. Otherwise: return spread of sym + enriched children as EnrichedClassSymbol.

    CRITICAL: The spread must use `...sym` to preserve all TransformedSymbol fields (name, kind, detail, deprecated, range, selectionRange). The `children` field from the spread is overwritten by the enriched children.

    CRITICAL: When calling buildMemberFqn, pass `sym.kind` (not parsed.kind). The sym.kind has the discriminating values like "constructor", "constant", "enumMember" that buildMemberFqn uses. parsed.kind is always just "method" or "field".

    Export only `enrichSymbols` -- `enrichOne` is an internal helper.
