### Integration Gap

**`remove_project` does not clean `dataDir`:** `remove-project.ts` cleans `tempDir` but not `dataDir`. The SIGINT/SIGTERM handlers in `index.ts` DO clean both. This means interactive `remove_project` calls in long-running sessions leak data dirs in `/tmp`. Fix is trivial: add `cleanupTempDir(proj.jdtls.dataDir)` after the `tempDir` cleanup.

**Severity:** Low — data dirs are ~100KB each, only accumulate on interactive project removal, cleaned on process exit.
