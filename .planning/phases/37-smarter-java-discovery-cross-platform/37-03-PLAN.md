Wire the `retryDegradedJdtLsSessions()` hook from Plan 02 into the three tool handlers identified by CONTEXT D-02 — `add_fabric_mod`, `refresh_project`, `refresh_project_members`. Each hook fires after the handler's existing work, unconditionally per D-04, so any newly-installed Java (or any newly-loaded gradle.properties value) unlocks the discovery chain for previously-degraded projects.

Output: Three thin handler edits; no domain logic change in this plan.
</objective>
