**src/project/gradle-parser.ts** -- Two exported functions:

1. `parseGradleProperties(content: string): Map<string, string>` -- Parse Java properties format:
   - Split on newlines, trim each line
   - Skip empty lines and lines starting with `#` or `!`
   - Split on first `=` sign, trim key and value
   - Return Map of key-value pairs

2. `parseBuildGradle(content: string, properties: Map<string, string>): GradleConfig` -- Parse build.gradle.kts:
   - Step 1: Substitute `${var_name}` references using properties map. Regex: `/\$\{(\w+)\}/g`, replace with `properties.get(match)` or leave as-is if not found.
   - Step 2: Strip single-line comments (`//...`) and block comments (`/* ... */`).
   - Step 3: Extract `dependencies { ... }` block using regex `/dependencies\s*\{([\s\S]*?)\n\}/` (match to closing `}` at start of line or with proper brace nesting).
   - Step 4: Extract individual dependency calls with regex `/(\w+)\(\s*"([^"]+)"\s*\)/g`. For each match, capture `configuration` (group 1) and the Maven coordinate string (group 2). Split coordinate on `:` into group, artifact, version. Store as `DependencyCoordinate`.
   - Step 5: Era detection -- if any dependency has `configuration === 'mappings'`, era is `'yarn'`; otherwise `'unobfuscated'`.
   - Step 6: Extract convenience fields from dependencies:
     - `minecraftVersion`: version from dependency where `configuration === 'minecraft'`
     - `yarnMappings`: version from dependency where `configuration === 'mappings'` (undefined if unobfuscated)
     - `loaderVersion`: version from dependency where artifact === `'fabric-loader'`
     - `fabricApiVersion`: version from dependency where artifact === `'fabric-api'`
   - Throw `DomainError('GRADLE_PARSE_MISSING_MINECRAFT', ...)` if no `minecraft(...)` dependency found.
   - Import `DomainError` from `../errors/domain-error.js`, import types from `./types.js`.

**src/project/loom-cache.ts** -- One exported function:

`resolveSourcesJarPath(config: GradleConfig): string` -- Construct the absolute path to the Minecraft sources jar:
   - Get home directory with `import { homedir } from 'node:os'`.
   - Base: `{homedir()}/.gradle/caches/fabric-loom/minecraftMaven/net/minecraft`
   - Yarn era (`config.mappingEra === 'yarn'`):
     - `artifactId = 'minecraft-merged'`
     - `sanitizedMcVersion = config.minecraftVersion.replace(/\./g, '_')`
     - `version = ${config.minecraftVersion}-net.fabricmc.yarn.${sanitizedMcVersion}.${config.yarnMappings}`
     - Example: `1.21.11-net.fabricmc.yarn.1_21_11.1.21.11+build.4`
   - Unobfuscated era (`config.mappingEra === 'unobfuscated'`):
     - `artifactId = 'minecraft-merged-deobf'`
     - `version = config.minecraftVersion`
   - Full path: `{base}/{artifactId}/{version}/{artifactId}-{version}-sources.jar`
   - Use `path.join()` for construction.
   - Does NOT check file existence (that is the loader's job in Plan 02).

**src/project/fabric-mod.ts** -- One exported function:

`parseFabricMod(content: string): FabricModJson` -- Parse and validate fabric.mod.json:
   - `JSON.parse(content)` the input string.
   - Validate with a Zod schema: `z.object({ schemaVersion: z.number(), id: z.string(), version: z.string(), name: z.string(), description: z.string().default(''), authors: z.array(z.union([z.string(), z.object({ name: z.string() })])).default([]), license: z.string().default(''), environment: z.string().default('*'), mixins: z.array(z.string()).default([]), depends: z.record(z.string(), z.string()).default({}) })`.
   - Use `.passthrough()` on the Zod schema so extra fields are preserved.
   - If JSON.parse fails, throw `DomainError('FABRIC_MOD_INVALID_JSON', 'fabric.mod.json is not valid JSON', [], ['Check for syntax errors in fabric.mod.json'])`.
   - If Zod validation fails, throw `DomainError('FABRIC_MOD_VALIDATION', message_from_zod, [], [])` using the formatted Zod error from `../errors/validation.js`.
   - Import `DomainError` from `../errors/domain-error.js`, import `formatZodError` from `../errors/validation.js`, import types from `./types.js`.
