<objective>
Add Windows-only drive-letter case-fold to `src/jdtls/uri-mapper.ts` `fromFileUri` via the surgical `prefixMatches` state machine (D-08 through D-11). Simultaneously migrate `toFileUri`'s internal `'file://' + normalizedTempDir` to `pathToFileUri(normalizedTempDir)` so emitted URIs are three-slash form — without this internal migration, the case-fold regex `/^file:\/\/\/[A-Za-z]:/` would never match the URIs the mapper itself produces (RESEARCH Open Landmine 8).

Purpose: Eclipse/EMF intentionally lowercases drive letters since EMF 2.9 (Bug 446987), but the LSP-layer normalization is not contractually documented. JDT LS may return `file:///c:/...` for a URI we sent as `file:///C:/...`, and the current `uri.startsWith(prefix)` rejects it. The fix is surgical: ONLY byte 8 (the drive letter) is case-insensitive, ONLY when both URIs match the drive-letter shape, ONLY on Windows. Everything else byte-exact (D-09).

Output: Modified `uri-mapper.ts` with `prefixMatches` helper + internal `pathToFileUri` use in prefix construction + new Windows-mocked test describes.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-36-03-01 | Spoofing | `fromFileUri` `prefixMatches` | accept | The case-fold only loosens byte 8 (the drive letter). UNC server names, share names, path segments, jar-entry tails are byte-exact per D-09 — a malicious URI cannot exploit case-fold to access a different file. The threat surface is "JDT LS returns a malformed URI" which is already accepted via Open Question 4 (RESOLVED) (loud `TypeError` failure at the consumer, caught and `continue`d past). |
| T-36-03-02 | Information disclosure | Cross-filesystem case-fold leakage | mitigate | D-09 / D-11 — case-fold is scoped to the single byte 8 of drive-letter URIs only. UNC, DOS device, volume GUID, Win32 namespace, and Unix URIs all use byte-exact compare. This prevents accidental file-disclosure on case-sensitive filesystems (ReFS, mounted ext4) where two filenames differ only in case. Mitigation enforced by the `DRIVE_LETTER_URI` regex gate in `prefixMatches`. |

No package installs. No new external input handling.
