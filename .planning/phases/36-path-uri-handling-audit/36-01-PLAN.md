<objective>
Create the new `src/platform/uri.ts` sibling module — two pure helpers wrapping Node's `node:url` builtins — and the matching `tests/platform/uri.test.ts` covering WIN-03 three-slash output / percent-encoding, UNIX-02 round-trip identity, AND the A2 darwin-host Windows-shape assertion that locks the wrapper signature. This module is the foundation every downstream plan in Phase 36 (Plans 02, 03, 04) imports from.

Purpose: Replace the brittle `'file://' + path` / `uri.replace('file://', '')` pattern with battle-tested Node stdlib wrappers. The wrapper indirection (rather than calling `pathToFileURL` directly at consumer sites) reserves a single home for any future Windows URI quirks (drive-letter case fold, `windows: true` option) without re-touching every callsite. The A2 assertion (Task 3) is a fail-fast gate that catches the one assumption RESEARCH flagged as MEDIUM-risk: if `pathToFileURL` on a darwin host does NOT auto-detect Windows-shaped input strings, the wrapper must grow a `{ windows?: boolean }` option to stay usable for Plan 03's Windows-mocked drive-letter tests.

Output: `src/platform/uri.ts` (~25 LOC pure module) + `tests/platform/uri.test.ts` (~100 LOC) covering both WIN-03 and UNIX-02 and the A2 host-darwin assertion. No consumer wiring yet — that happens in Plans 02, 03, 04.
</objective>
