**Create `src/jdtls/workspace-sync.ts`** with these exports:

1. **`extractStudyJarToWorkspace(studyJar: StudyJar, tempDir: string, jarReader: JarReader): Promise<string>`**
   - Compute `dirName = jarIdToDirName('study:' + studyJar.name)`
   - Create `depDir = join(tempDir, dirName)`
   - Use `createJarAdapter(jarReader, studyJar.jarPath)` to get adapter
   - Call `adapter.listJavaEntries()`, iterate entries, for each: `mkdir(dirname(targetPath), { recursive: true })` then `writeFile(targetPath, content)`
   - Return `dirName`
   - On error, attempt cleanup of `depDir` with `rm(depDir, { recursive: true, force: true })`, then rethrow

2. **`removeStudyJarFromWorkspace(studyJarName: string, tempDir: string): Promise<void>`**
   - Compute `dirName = jarIdToDirName('study:' + studyJarName)`
   - Delete `join(tempDir, dirName)` with `rm(depDir, { recursive: true, force: true })`

3. **`waitForWorkspaceSync(endpoint: JSONRPCEndpoint, timeoutMs: number): Promise<void>`**
   - Probe-based readiness: initial delay 500ms, then send `workspace/symbol` request with query `'*'`
   - If result is an array (even empty), workspace is responsive — return
   - If request throws, retry with exponential backoff (multiply delay by 1.5, cap at 5000ms)
   - If `Date.now() > deadline`, throw `new Error('JDT LS did not complete workspace sync within ${timeoutMs}ms')`
   - Note: Use query `'*'` rather than a specific class name because we don't know what classes are in an arbitrary study jar. The goal is to confirm JDT LS is responsive after the classpath change, not to find a specific symbol.

4. **`isWorkspaceSynced(studyJarName: string, jdtls: JdtLsSession | undefined): boolean`**
   - If `!jdtls?.available`, return `false`
   - Return `jdtls.jarIdToDirName.has('study:' + studyJarName)`

5. **`syncStudyJarToWorkspace(studyJar: StudyJar, jdtls: JdtLsSession | undefined, jarReader: JarReader): Promise<{ synced: boolean; warning?: string }>`**
   - If `!jdtls?.available || !jdtls.endpoint`, return `{ synced: false, warning: 'Note: JDT LS unavailable -- semantic navigation disabled' }`
   - Try block:
     a. `const dirName = await extractStudyJarToWorkspace(studyJar, jdtls.tempDir, jarReader)`
     b. `jdtls.jarIdToDirName.set('study:' + studyJar.name, dirName)`
     c. Collect all dirs: `const allDirs = Array.from(jdtls.jarIdToDirName.values())`
     d. Generate classpath: `const classpathXml = generateClasspathFile(allDirs)`
     e. Resolve temp dir: `const resolvedTempDir = realpathSync(jdtls.tempDir)` (import from `node:fs`)
     f. Write classpath: `await writeFile(join(resolvedTempDir, '.classpath'), classpathXml)`
     g. Notify JDT LS: `jdtls.endpoint.notify('workspace/didChangeWatchedFiles', { changes: [{ uri: 'file://' + resolvedTempDir + '/.classpath', type: 2 }] })`
     h. Wait: `await waitForWorkspaceSync(jdtls.endpoint, 120_000)`
     i. Return `{ synced: true }`
   - Catch block: delete `jdtls.jarIdToDirName` entry for `'study:' + studyJar.name`, return `{ synced: false, warning: 'Workspace sync failed: ' + (err instanceof Error ? err.message : String(err)) }`

6. **`unsyncStudyJarFromWorkspace(studyJarName: string, jdtls: JdtLsSession | undefined): Promise<{ synced: boolean }>`**
   - If `!jdtls?.available || !jdtls.endpoint`, return `{ synced: false }`
   - Try block:
     a. `await removeStudyJarFromWorkspace(studyJarName, jdtls.tempDir)` (delete extracted dir first)
     b. `jdtls.jarIdToDirName.delete('study:' + studyJarName)` (update map)
     c. Regenerate classpath: collect all dirs from `jdtls.jarIdToDirName.values()`, call `generateClasspathFile`, write to `join(realpathSync(jdtls.tempDir), '.classpath')`
     d. Notify: `jdtls.endpoint.notify('workspace/didChangeWatchedFiles', { changes: [{ uri: 'file://' + realpathSync(jdtls.tempDir) + '/.classpath', type: 2 }] })`
     e. Wait: `await waitForWorkspaceSync(jdtls.endpoint, 120_000)`
     f. Return `{ synced: true }`
   - Catch block: still delete from `jdtls.jarIdToDirName` (best-effort cleanup), return `{ synced: false }`
