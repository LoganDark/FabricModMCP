Export `extractSourcesToTemp`:
```typescript
export async function extractSourcesToTemp(
  dependencies: Map<string, DependencyEntry>,
  rootPath: string,
  jarReader: JarReader,
): Promise<{ tempDir: string; jarIdToDirNameMap: Map<string, string> }>
```

Steps:
1. Create temp directory: `join(tmpdir(), 'mcp-jdtls-' + randomUUID())`
2. For each dependency in the Map where `available === true`:
   - Compute directory name using `jarIdToDirName(dep.id)` from `../jdtls/uri-mapper.js`
   - Create subdirectory: `join(tempDir, dirName)`
   - Use `createSourceAdapter(jarReader, dep, rootPath)` to get a SourceAdapter
   - Call `listJavaEntries()` to get all .java entry paths
   - For each entry, call `readEntry(entryPath)` and write to `join(tempDir, dirName, entryPath)`
   - Create intermediate directories as needed (`mkdir(..., { recursive: true })`)
   - Record `dep.id -> dirName` in the return map
3. Generate `.project` file at `join(tempDir, '.project')`:
```xml
<?xml version="1.0" encoding="UTF-8"?>
<projectDescription>
  <name>mcp-sources</name>
  <buildSpec>
    <buildCommand>
      <name>org.eclipse.jdt.core.javabuilder</name>
    </buildCommand>
  </buildSpec>
  <natures>
    <nature>org.eclipse.jdt.core.javanature</nature>
  </natures>
</projectDescription>
```
4. Generate `.classpath` file at `join(tempDir, '.classpath')` with a `<classpathentry kind="src" path="{dirName}"/>` for each extracted directory, plus `<classpathentry kind="con" path="org.eclipse.jdt.launching.JRE_CONTAINER"/>` and `<classpathentry kind="output" path="bin"/>`.
5. Return `{ tempDir, jarIdToDirNameMap }`.

Export `detectJava`:
```typescript
export function detectJava(): { javaPath: string; version: number } | { javaPath: null; error: string }
```
1. Try `process.env.JAVA_HOME`: if set, use `join(JAVA_HOME, 'bin', 'java')`.
2. Otherwise try `java` on PATH.
3. Run `{javaPath} --version`, parse first line for version number (e.g., `openjdk 21.0.1` -> 21).
4. If version < 21, return error `"Java ${version} found but JDT LS requires Java 21+"`.
5. If no java found or execSync throws, return error `"Java not found. Set JAVA_HOME or add java to PATH."`.

Export `findJdtLs`:
```typescript
export function findJdtLs(): { jdtlsHome: string } | { jdtlsHome: null; error: string }
```
1. Check `process.env.JDTLS_HOME`. If set and directory exists, return it.
2. Try common locations: `~/.local/share/jdtls`, `/usr/local/share/jdtls`, `~/jdtls`.
3. If none found, return error `"JDT LS not found. Set JDTLS_HOME environment variable. Download from https://download.eclipse.org/jdtls/milestones/"`.

Export `startJdtLs`:
```typescript
export async function startJdtLs(
  javaPath: string,
  jdtlsHome: string,
  workspaceDir: string,
): Promise<{ process: ChildProcess; client: LspClient; endpoint: JSONRPCEndpoint }>
```
1. Create a data directory: `join(tmpdir(), 'mcp-jdtls-data-' + randomUUID())`
2. Find the launcher jar: use `glob` to find `plugins/org.eclipse.equinox.launcher_*.jar` in jdtlsHome
3. Determine config directory based on `process.platform`: `config_mac` for darwin, `config_linux` for linux, `config_win` for win32
4. Spawn java process with args from the RESEARCH.md code example:
   ```
   -Declipse.application=org.eclipse.jdt.ls.core.id1
   -Dosgi.bundles.defaultStartLevel=4
   -Declipse.product=org.eclipse.jdt.ls.core.product
   -Xmx1G
   --add-modules=ALL-SYSTEM
   --add-opens java.base/java.util=ALL-UNNAMED
   --add-opens java.base/java.lang=ALL-UNNAMED
   -jar {launcherJar}
   -configuration {configDir}
   -data {dataDir}
   ```
5. Create `JSONRPCEndpoint` from `ts-lsp-client` using proc.stdin/stdout
6. Create `LspClient` from the endpoint
7. Send `initialize` request with:
   - `processId: process.pid`
   - `rootUri: 'file://' + workspaceDir`
   - `capabilities.textDocument.definition.dynamicRegistration: false`
   - `capabilities.textDocument.references.dynamicRegistration: false`
   - `workspaceFolders: [{ uri: 'file://' + workspaceDir, name: 'sources' }]`
   - `initializationOptions.settings.java.autobuild.enabled: true`
   - `initializationOptions.settings.java.import.maven.enabled: false`
   - `initializationOptions.settings.java.import.gradle.enabled: false`
8. Send `initialized` notification
9. Wait for JDT LS readiness: poll with a timeout of 60 seconds. Listen for `language/status` notifications with `"ServiceReady"` in the message, or use a simple retry loop attempting a basic LSP request until it returns non-empty.
10. Return the process, client, endpoint

Export `shutdownJdtLs`:
```typescript
export async function shutdownJdtLs(client: LspClient, proc: ChildProcess): Promise<void>
```
1. Send `shutdown` request via client
2. Send `exit` notification via client
3. If process hasn't exited after 5 seconds, kill it

Add this block after jar registration:
```typescript
// Initialize JDT LS (eager, per user decision)
const javaResult = detectJava();
const jdtlsResult = findJdtLs();

if (javaResult.javaPath === null) {
  project.jdtls = {
    available: false,
    failureReason: javaResult.error,
    tempDir: '',
    dataDir: '',
    jarIdToDirName: new Map(),
  };
  logger.info(`JDT LS unavailable for ${projectName}: ${javaResult.error}`);
} else if (jdtlsResult.jdtlsHome === null) {
  project.jdtls = {
    available: false,
    failureReason: jdtlsResult.error,
    tempDir: '',
    dataDir: '',
    jarIdToDirName: new Map(),
  };
  logger.info(`JDT LS unavailable for ${projectName}: ${jdtlsResult.error}`);
} else {
  try {
    const extraction = await extractSourcesToTemp(
      project.dependencyJars,
      project.rootPath,
      jarReader,
    );
    const { process: lspProcess, client: lspClient } = await startJdtLs(
      javaResult.javaPath,
      jdtlsResult.jdtlsHome,
      extraction.tempDir,
    );
    project.jdtls = {
      available: true,
      tempDir: extraction.tempDir,
      dataDir: '', // set by startJdtLs internally
      jarIdToDirName: extraction.jarIdToDirNameMap,
      client: lspClient,
      process: lspProcess,
    };
    logger.info(`JDT LS initialized for ${projectName}`);
  } catch (err) {
    project.jdtls = {
      available: false,
      failureReason: `JDT LS initialization failed: ${err instanceof Error ? err.message : String(err)}`,
      tempDir: '',
      dataDir: '',
      jarIdToDirName: new Map(),
    };
    logger.warn(`JDT LS failed for ${projectName}: ${project.jdtls.failureReason}`);
  }
}
```

Add `jdtlsAvailable: project.jdtls?.available ?? false` to the success envelope data object.
