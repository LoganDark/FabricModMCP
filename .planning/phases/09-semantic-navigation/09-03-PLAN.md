Create `src/tools/find-definition.ts` exporting `registerFindDefinitionTool(server: McpServer)`.

**Parameter schema:** Identical to `locate_in_source`:
```typescript
inputSchema: {
  project: z.string().optional().describe('Project name (optional if only one project loaded or default is set)'),
  jar: z.string().optional().describe('Specific jar ID where the symbol to navigate FROM is located (default: search all jars containing the class)'),
  class: z.string().describe('Fully-qualified class name using dot notation (e.g., net.minecraft.client.MinecraftClient)'),
  patterns: z.array(z.string()).min(1).describe('Array of cascading regex patterns to locate the symbol position. Each pattern narrows within the previous match. Use inline flags like (?i), (?s), (?m).'),
}
```

**Tool flow** (one-shot, per user decision):

1. **Resolve project** using `projectStore.resolveProject(project)` with DomainError catch pattern (same as locate-in-source).

2. **Check JDT LS availability:**
   ```typescript
   if (!loadedProject.jdtls?.available || !loadedProject.jdtls.client) {
     return makeError('JDTLS_NOT_AVAILABLE',
       `JDT LS not available for project '${loadedProject.name}': ${loadedProject.jdtls?.failureReason ?? 'not initialized'}`,
       [loadedProject.name],
       ['Ensure Java 21+ is installed and JDTLS_HOME is set']);
   }
   ```
   Hard-error, no fallback (per user decision).

3. **Convert FQN to entry path** — same logic as locate-in-source (lastDot, packagePath, simpleNameWithInner).

4. **Resolve position via cascading regex:**
   - If `jar` is specified: read source from that jar, run cascadeRegex
   - If `jar` is not specified: iterate all available jars in priority order (same as locate-in-source all-jars mode), find the FIRST jar containing the class, run cascadeRegex on it
   - If cascadeRegex fails, return the failure using the same `{ results: [], failures: [...] }` pattern

5. **Build file URI for the cascading regex target:**
   - Create URI mapper: `createUriMapper(loadedProject.jdtls.tempDir, loadedProject.jdtls.jarIdToDirName)`
   - Build URI: `uriMapper.toFileUri(sourceJarId, entryPath)`

6. **Send textDocument/didOpen** for the target file:
   ```typescript
   const sourceText = buffer.toString('utf-8');
   await loadedProject.jdtls.client.didOpen({
     textDocument: {
       uri: fileUri,
       languageId: 'java',
       version: 1,
       text: sourceText,
     },
   });
   ```

7. **Send textDocument/definition** request:
   ```typescript
   const lspPosition = { line: cascadeResult.line - 1, character: cascadeResult.column - 1 };
   const defResult = await loadedProject.jdtls.client.definition({
     textDocument: { uri: fileUri },
     position: lspPosition,
   });
   ```

8. **Send textDocument/didClose** for the target file:
   ```typescript
   await loadedProject.jdtls.client.didClose({ textDocument: { uri: fileUri } });
   ```

9. **Process definition results:**
   - `defResult` may be `Location | Location[] | LocationLink[] | null`
   - Normalize to an array of locations
   - For each location:
     a. Map URI back to jar ID + entry path: `uriMapper.fromFileUri(loc.uri)`
     b. If mapping fails (URI outside known jars), skip
     c. Read the source file from the extracted temp dir (use `readFile` on the filesystem path derived from the URI)
     d. Convert entry path to class name: `entryPathToClassName(mapping.entryPath)`
     e. Extract enclosing context: `extractEnclosingContext(source, loc.range.start.line + 1)` (convert 0-based LSP line to 1-based)
     f. Look up the DependencyEntry for the jar ID from `loadedProject.dependencyJars` to get category and provenance chains
     g. Build `NavigationResult`:
        ```typescript
        {
          jar: mapping.jar,
          category: dep.category,
          provenanceChains: dep.provenanceChains,
          entryPath: mapping.entryPath,
          className,
          line: loc.range.start.line + 1,
          column: loc.range.start.character + 1,
          context: contextSnippet,
        }
        ```

10. **Return response:**
    ```typescript
    const envelope = makeSuccess({ results, sourcePosition: { jar: sourceJarId, class: className, line: cascadeResult.line, column: cascadeResult.column } }, { provenance });
    return {
      content: [{ type: 'text' as const, text: JSON.stringify(envelope, null, 2) }],
      structuredContent: envelope,
    };
    ```

If no definition locations found, return success with empty results array (not an error — some symbols genuinely have no navigable definition).

Import `readFile` from `node:fs/promises` for reading extracted source files from the temp directory.
