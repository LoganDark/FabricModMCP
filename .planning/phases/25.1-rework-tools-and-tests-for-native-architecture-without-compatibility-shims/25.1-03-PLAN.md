**Create `src/tools/get-project-info.ts`:**
- Tool name: `get_project_info`
- Input schema: `{ project: PARAMS.project }` — optional, resolves via resolveProjectSafely
- Logic: Iterate `loadedProject.children` to build an array of member summaries:
  ```typescript
  const members = [];
  for (const [name, child] of loadedProject.children) {
      if (child.kind === 'fabric-mod') {
          members.push({
              name,
              kind: 'fabric-mod' as const,
              minecraftVersion: child.gradleConfig.minecraftVersion,
              mappingEra: child.gradleConfig.mappingEra,
              dependencyCount: child.dependencyJars.size,
          });
      } else if (child.kind === 'study-jar') {
          members.push({
              name,
              kind: 'study-jar' as const,
              jarPath: child.jarPath,
              autoInclude: child.autoInclude,
          });
      }
  }
  ```
- Return success with `{ project: loadedProject.name, activeChild: loadedProject.activeChild, memberCount: members.length, members }`
- NO compat imports, NO toggle flags — always returns the full overview

**Create `src/tools/get-member-info.ts`:**
- Tool name: `get_member_info`
- Input schema: `{ project: PARAMS.project, member: z.string().describe('Name of the member to inspect') }`
- Logic:
  1. Resolve project, get child via `loadedProject.children.get(member)`
  2. If not found, return error CHILD_NOT_FOUND
  3. If `child.kind === 'fabric-mod'`: return the three sections from get-project-metadata.ts:
     - `projectInfo`: minecraftVersion, yarnMappings, loaderVersion, fabricApiVersion, mappingEra (from child.gradleConfig)
     - `modInfo`: spread child.fabricMod (id, name, version, description, authors, etc.)
     - `jarInventory`: map over child.dependencyJars with id, group, artifact, version, category, available, sourcesJarPath — follow the exact format from get-project-metadata.ts
  4. If `child.kind === 'study-jar'`: return studyJarInfo: name, jarPath, mtime, size, autoInclude, stats
- Return success envelope with the member's detailed data
