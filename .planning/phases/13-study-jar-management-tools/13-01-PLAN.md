Create four tool files following the exact pattern from `configure-filters.ts`. Each file exports a single `register*Tool(server: McpServer): void` function.

**File 1: `src/tools/add-study-jar.ts`** — `registerAddStudyJarTool`
- Tool name: `'add_study_jar'`
- Title: `'Add Study Jar'`
- inputSchema: `{ project: PARAMS.project, path: z.string().describe('Absolute path to a sources JAR file'), name: z.string().optional().describe('Display name for the study jar (auto-derived from filename if omitted)') }`
- Handler logic:
  1. `resolveProjectSafely(project)` — return error if not ok
  2. `try { const studyJar = await createStudyJar(path, name, loadedProject); }` — createStudyJar validates path, opens ZIP, computes stats, checks duplicates, derives name if undefined
  3. `loadedProject.studyJars.set(studyJar.name, studyJar);`
  4. `jarReader.addProjectJar(loadedProject.name, studyJar.jarPath);`
  5. Return dual response: text = `Added study jar '${studyJar.name}' (${studyJar.stats.classCount} classes, ${studyJar.stats.packageCount} packages)`, structuredContent = `makeSuccess({ name: studyJar.name, path: studyJar.jarPath, autoInclude: studyJar.autoInclude, stats: studyJar.stats })`
  6. Catch `DomainError` — convert to `returnError(err.code, err.message, err.tried, err.suggestions)`
- Imports: `z` from `'zod'`, `McpServer` from SDK, `makeSuccess` from `'../types/envelope.js'`, `resolveProjectSafely`, `returnError` from `'./tool-helpers.js'`, `TOOL_DESCRIPTIONS`, `PARAMS` from `'./descriptions.js'`, `createStudyJar` from `'../project/study-jar.js'`, `jarReader` from `'./shared-jar-reader.js'`, `DomainError` from `'../errors/domain-error.js'`

**File 2: `src/tools/remove-study-jar.ts`** — `registerRemoveStudyJarTool`
- Tool name: `'remove_study_jar'`
- Title: `'Remove Study Jar'`
- inputSchema: `{ project: PARAMS.project, names: z.array(z.string()).min(1).describe('Study jar name(s) to remove') }`
- Handler logic:
  1. `resolveProjectSafely(project)` — return error if not ok
  2. Pre-validate ALL names exist: loop over `names`, if any `!loadedProject.studyJars.has(name)`, return `returnError('STUDY_JAR_NOT_FOUND', \`Study jar '${name}' not found on project '${loadedProject.name}'\`, [name], ['Use list_study_jars to see available study jars'])`
  3. Apply removals: for each name, get the `StudyJar` from map, call `await jarReader.removeProjectJar(loadedProject.name, studyJar.jarPath)`, call `evictEntryIndex(studyJar.jarPath)`, call `loadedProject.studyJars.delete(name)`
  4. Return dual response: text = `Removed ${names.length} study jar(s): ${names.join(', ')}`, structuredContent = `makeSuccess({ removed: names, remaining: loadedProject.studyJars.size })`
- Imports: same pattern as add tool, plus `evictEntryIndex` from `'../browsing/entry-index-cache.js'`

**File 3: `src/tools/list-study-jars.ts`** — `registerListStudyJarsTool`
- Tool name: `'list_study_jars'`
- Title: `'List Study Jars'`
- inputSchema: `{ project: PARAMS.project }`
- Handler logic:
  1. `resolveProjectSafely(project)` — return error if not ok
  2. Build array from `loadedProject.studyJars.values()`: `{ name, path: jar.jarPath, autoInclude: jar.autoInclude, stats: jar.stats }`
  3. Return dual response: text = `jars.length === 0 ? 'No study jars configured' : \`${jars.length} study jar(s): ${jars.map(j => j.name).join(', ')}\``, structuredContent = `makeSuccess({ jars, count: jars.length })`
- Imports: subset of add tool imports (no createStudyJar, no jarReader, no DomainError)

**File 4: `src/tools/configure-study-jar.ts`** — `registerConfigureStudyJarTool`
- Tool name: `'configure_study_jar'`
- Title: `'Configure Study Jar'`
- inputSchema: `{ project: PARAMS.project, names: z.array(z.string()).min(1).describe('Study jar name(s) to configure'), autoInclude: z.boolean().optional().describe('Whether to include in default tool results when jars parameter is omitted') }`
- Handler logic:
  1. `resolveProjectSafely(project)` — return error if not ok
  2. Pre-validate ALL names exist (same pattern as remove tool)
  3. Apply configuration: for each name, get `StudyJar`, if `autoInclude !== undefined` set `studyJar.autoInclude = autoInclude`. Build `updated` array: `{ name, autoInclude: studyJar.autoInclude }`
  4. Return dual response: text = `Configured ${names.length} study jar(s): ${names.join(', ')}`, structuredContent = `makeSuccess({ updated })`

All files MUST use tab indentation. Do NOT nest JSON.stringify'd text inside the text content -- text must be human-readable plain strings, not JSON.
