<objective>
Add optional context lines parameter to `locate_in_source` that extends matches to whole line boundaries with surrounding context lines.

Purpose: Currently locate_in_source returns offset/line/column but no surrounding text. The context parameter lets users get the matched line plus surrounding lines, eliminating the need for a separate read_source call just to see context around a match.

Output: Modified `src/tools/locate-in-source.ts` with context parameter, `LocateResultContext` type in types.ts, updated description, new test cases.

    function extractContext(
      source: string,
      line: number,
      linesBefore: number,
      linesAfter: number,
    ): LocateResultContext {
      const lines = source.split('\n');
      const totalLines = lines.length;
      const startLine = Math.max(1, line - linesBefore);
      const endLine = Math.min(totalLines, line + linesAfter);
      const text = lines.slice(startLine - 1, endLine).join('\n');
      return { text, startLine, endLine };
    }
