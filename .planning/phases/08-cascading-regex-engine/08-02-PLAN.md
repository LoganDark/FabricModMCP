    **Tool registration:**
    ```typescript
    export function registerLocateInSourceTool(server: McpServer): void {
    	server.registerTool(
    		'locate_in_source',
    		{
    			title: 'Locate in Source',
    			description: 'Locate a precise position in Java source using cascading regex patterns. Each pattern narrows within the previous match. Returns character offset, line, and column. Use inline flags like (?i) for case-insensitive or (?s) for dotAll matching.',
    			inputSchema: {
    				project: z.string().optional().describe('Project name (optional if only one project loaded or default is set)'),
    				jar: z.string().optional().describe('Specific jar ID to search (default: search all jars containing the class)'),
    				class: z.string().describe('Fully-qualified class name using dot notation (e.g., net.minecraft.client.MinecraftClient)'),
    				patterns: z.array(z.string()).min(1).describe('Array of regex patterns. Each searches within the previous match. First searches entire source. Use (?i), (?s), (?m) prefixes for per-pattern flags.'),
    			},
    		},
    		async ({ project, jar, class: className, patterns }) => { ... },
    	);
    }
    ```

    **Handler logic (inside the async callback):**

    1. **Project resolution** -- identical to `read-source.ts` lines 51-64: try `projectStore.resolveProject(project)`, catch DomainError, return `makeError` envelope.

    2. **FQN to entry path** -- identical to `read-source.ts` lines 67-75:
       ```typescript
       const lastDot = className.lastIndexOf('.');
       let entryPath: string;
       if (lastDot === -1) {
       	entryPath = `${className}.java`;
       } else {
       	const packagePath = className.substring(0, lastDot).replaceAll('.', '/');
       	const simpleNameWithInner = className.substring(lastDot + 1);
       	entryPath = `${packagePath}/${simpleNameWithInner}.java`;
       }
       ```

    3. **Specific jar mode** (when `jar` is provided):
       - Look up `dep` from `loadedProject.dependencyJars.get(jar)`.
       - If not found, return `makeError('JAR_NOT_FOUND', ...)`.
       - If not available, return `makeError('JAR_NOT_AVAILABLE', ...)`.
       - Read source: `const adapter = createSourceAdapter(jarReader, dep, loadedProject.rootPath); const buffer = await adapter.readEntry(entryPath); const source = buffer.toString('utf-8');`
       - Run cascade: `const result = cascadeRegex(source, patterns);`
       - If `result.success`, return `makeSuccess({ results: [{ jar: dep.id, category: dep.category, provenanceChains: dep.provenanceChains, ...result }], failures: [] }, { provenance: { tool: 'locate_in_source', project: loadedProject.name, class: className } })`.
       - If `!result.success`, return `makeSuccess({ results: [], failures: [{ jar: dep.id, category: dep.category, provenanceChains: dep.provenanceChains, ...result }] }, { provenance: ... })`.
       - Wrap readEntry in try/catch for class-not-found.

    4. **All-jars mode** (when `jar` is not provided):
       - Get filtered deps: `const filtered = getFilteredDependencies(loadedProject.dependencyJars, loadedProject.filterConfig);`
       - Sort by priority using `CATEGORY_PRIORITY` (copy from `read-source.ts` -- same `const CATEGORY_PRIORITY: Record<JarCategory, number>` and `sortByPriority` function).
       - Iterate sorted deps. For each available dep:
         - Try reading source via `createSourceAdapter`. If readEntry throws, skip (class not in this jar).
         - Run `cascadeRegex(source, patterns)`.
         - If success, push to `results` array with jar/category/provenance + cascade result fields.
         - If failure, push to `failures` array with jar/category/provenance + cascade failure fields.
       - If both `results` and `failures` are empty (class not found anywhere), return `makeError('CLASS_NOT_FOUND', ...)`.
       - Return `makeSuccess({ results, failures }, { provenance: { tool: 'locate_in_source', project: loadedProject.name, class: className } })`.

    5. **Response shape per result/failure item:**
       ```typescript
       interface LocateResult {
       	jar: string;
       	category: JarCategory;
       	provenanceChains: string[][];
       	steps: CascadeStep[];
       	offset: number;
       	line: number;
       	column: number;
       }
       interface LocateFailure {
       	jar: string;
       	category: JarCategory;
       	provenanceChains: string[][];
       	steps: CascadeStep[];
       	failedStep: number;
       	error?: string;
       }
       ```

    6. **Return format** -- dual `content` (text JSON) + `structuredContent`, identical pattern to all other tools.
